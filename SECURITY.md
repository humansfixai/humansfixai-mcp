# Security

If you find a security problem with the humans fix ai connector or the website, please tell us privately before you share it publicly.

- Email: hello@humansfix.ai
- Say what you found, how to reproduce it, and which address or tool is involved.
- Do not include other people's data, passwords or keys in your report.

We will reply as soon as we can and keep you informed while we look into it.

What is in scope: the connector at `https://humansfix.ai/mcp`, its server card, and the website at `https://humansfix.ai`. This repository only contains documentation and examples, so problems here are usually wording or example mistakes. You can open an issue for those.
